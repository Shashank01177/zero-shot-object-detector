Understanding Zero-Shot Object Detection

How open-vocabulary multimodal vision-language models locate objects without training on predefined labels.

1

Open-Vocabulary Vision Transformer

Standard detectors (like standard YOLO or Faster R-CNN) have fixed classifier heads with fixed classes (e.g. 80 COCO classes). In contrast, OWLv2 replaces fixed classification weights with text embeddings produced by a language encoder (like CLIP).

2

Multimodal Joint Embedding Space

Image patches and textual prompt tokens are projected into the same high-dimensional embedding space. Dot product similarity between visual patch tokens and text query embeddings directly determines class presence scores.

3

Class-Agnostic Box Regression

A lightweight MLP head predicts bounding box coordinates \([x, y, w, h]\) relative to patch tokens. Because the box regressor is class-agnostic, it can localize novel, unseen objects with precision.

4

Non-Maximum Suppression (NMS)

When multiple candidate tokens fire for the same physical object, Non-Maximum Suppression calculates the Intersection-over-Union (IoU) and retains only the highest-scoring candidate, preventing duplicate boxes.

Mathematical Foundation
Similarity Score: S(r, q) = ( v_r · w_q ) / ( ||v_r|| * ||w_q|| )
IoU(Box_A, Box_B) = Area(Box_A ∩ Box_B) / Area(Box_A ∪ Box_B)

Where \(v_r\) is the visual representation vector of region \(r\) and \(w_q\) is the normalized text embedding of query \(q\).
